# references/design-language.md · 单色纸感页面语言

> 权威来源：`DESIGN.md` 第 1–4、7 节与 `Plan.md` §3.6、§9.6。页面是「纸面 stage」，不是网页玩具：安静、单色、有网格、有留白。
> 本文件只给页面可直接执行的规则；与 `DESIGN.md` 冲突时以 `DESIGN.md` 为准。

## 1. 三条铁律

1. **内容优先**：去掉所有装饰后页面仍成立。层级靠字号、字重、留白、1px 边框，不靠颜色。
2. **单色对比**：只有黑、白、灰。强调 = 墨色反转（深底浅字）或加粗描边；没有品牌色、状态色、高亮色。
3. **克制动效**：动效只解释状态变化（出现、切换、推进），150 / 200 / 400ms；禁止循环装饰、弹跳、漂浮、视差。

## 2. 可用 token（只能用这些，且只用 `var()`）

| 变量 | 用途 | 页面典型写法 |
| --- | --- | --- |
| `--mp-surface` | 页面最底层 | 一般不用，页面根用 panel |
| `--mp-panel` | 纸面底色 | `background: var(--mp-panel)` |
| `--mp-raised` | 次级分区、图底、卡片内嵌区 | 演示区、SVG 网格底 |
| `--mp-border` | 默认 1px 边框、分割线 | `border: 1px solid var(--mp-border)` |
| `--mp-border-strong` | 强调边框、虚线框、当前项 | `border-color: var(--mp-border-strong)` |
| `--mp-ink` | 主文字、图形主色、主按钮底 | `color: var(--mp-ink)` |
| `--mp-muted` | 次级说明 | 副标题、图注 |
| `--mp-faint` | 序号、索引、极次要信息 | 数组下标、年份刻度 |
| `--mp-invert` | 反转强调块、选中/当前态 | 当前节点、mid 单元格、主按钮 |
| `--mp-invert-ink` | 反转块上的文字 | 反转块内 `color` |
| `--mp-code-bg` | 行内代码、代码块 | `<code>` 底 |
| `--mp-font-sans` | 正文 | `font-family: var(--mp-font-sans)` |
| `--mp-font-mono` | 数字、代码、坐标 | 数值、矩阵元素 |

- 除上述变量外只允许 `currentColor` 与 `transparent`。**禁止** `#fff`、`rgb()`、`hsl()`、`black`、`white`。
- 不要自造 `--mp-*` 变量：运行时变量是契约的一部分，自造会与宿主 token 混淆。
- 深浅色由宿主切换 `data-mp-theme`，页面不写 `@media (prefers-color-scheme)`、不写 `dark:` 变体。

## 3. 字号与行高

| 角色 | 建议 | 说明 |
| --- | --- | --- |
| 页面主标题 | `clamp(22px, 2.6vw, 40px)`，700，`line-height: 1.15`，`letter-spacing: -0.01em` | 一屏一个主标题 |
| 页面副标题 | `clamp(13px, 1.1vw, 17px)`，`--mp-muted`，行高 1.6 | ≤ 40 字 |
| 区块标题 | `clamp(15px, 1.2vw, 19px)`，600 | 最多 3 层标题 |
| 正文/说明 | `clamp(13px, 1vw, 16px)`，行高 1.65–1.75 | 中文必须给足行高 |
| 数字/代码 | `--mp-font-mono`，与正文字号同级 | 序列、下标、矩阵元素 |
| 微型标签 | 11–12px，600，`letter-spacing: .12em`，`--mp-faint` | 全大写英文或短中文标签 |

- 最小字号 12px（契约硬下限 11px）；不要用细体（300）做“高级感”。
- 标题不要超过两级视觉重量；不要用字号大小制造超过 3 个层级。
- 长标题、长公式、长数字必须换行或缩放，不得撑破容器。

## 4. 间距、留白、圆角、边框

- 间距阶梯（近似）：4 / 8 / 12 / 16 / 24 / 32 / 40；用 `clamp()` 让大屏更松：`gap: clamp(10px, 1.5vh, 20px)`。
- 页面内边距：`clamp(16px, 2.4vw, 36px)`；纸面卡内边距：`clamp(14px, 1.8vw, 26px)`。
- 圆角：卡片 18–24px，按钮/单元格 12–16px，徽章/圆点 `999px`；不要 0–4px 锐角，也不要超过 24px。
- 边框是主角：**静态元素默认无阴影**，只用 1px `--mp-border`；需要强调时换 `--mp-border-strong` 或 2px `--mp-ink`。
- 阴影只允许极少量用于浮层；页面内**默认不用阴影**，绝不用彩色阴影。若用，只能是 `0 0 0 1px var(--mp-border)` 这类描边式阴影。

## 5. 密度预算（教学页 v1.1）

| 项 | 预算 |
| --- | --- |
| 核心观点 | 1 个 |
| 单层可见正文 | 建议 450–500 汉字（超出用渐进式披露） |
| 单页总正文 | ≤ 700 汉字（硬上限；超出必须拆页） |
| 可见内容块 | 3–6 个（含主视觉） |
| 页内总块数 | 5–8 个（含隐藏层） |
| 主交互 | 1 个（3–5 个学习状态，可带重置/上一步） |
| 检查/揭示 | ≤1 个 |
| 可见公式 | ≤3 个；总公式 ≤6 个 |
| 按钮 | 1 个主按钮 + 至多 2 个次按钮 |
| 列表/步骤 | 单层最多 6 条；超出用分步揭示，不要缩小字号 |
| 表格行 | 单层最多 5 行 |
| 图表元素 | 一张主图；不要并排两张同等重量的图 |

- 整页 700 字是总预算，不是要求一次铺满；单层控制在 450–500 字，其余用步骤器/标签页/折叠答案承载。
- 优先复用 Shell 注入的 `.mp-page/.mp-card/.mp-stepper/.mp-check/.mp-option/.mp-btn` 等 kit class，只写必要局部样式。
- 步骤/节点多时用**分步揭示**（一次显示 1–4 条），而不是一次全排。

## 6. 明确禁止（与 DESIGN.md 反对清单一致）

- 彩色渐变、AI 光晕、霓虹描边、玻璃拟态（backdrop-filter 模糊卡片）。
- 红/绿/黄状态色、彩色标签、彩色阴影、彩色图表。
- 大圆角气泡堆叠、胶囊按钮泛滥、悬浮客服球。
- 插画、卡通吉祥物、**emoji 装饰**、3D 图标。
- 弹跳/弹性缓动、持续漂浮动画、背景视频、视差滚动。
- Web Font / 外部字体、外部图片、外部图标库；图标只能用内联 SVG 路径。
- 多套并存的按钮/卡片风格；同一页面不要混用两种卡片语言。
- 用颜色表达状态（对/错、成功/失败）：用图标、文案、边框、反转表达。

## 7. 四种风格预设的页面差异（不引入彩色）

| 预设 | 页面手法 | 注意 |
| --- | --- | --- |
| 讲义 editorial | 单栏 + 侧注，大标题，段落淡入 | 不要做成纯文字页，仍要有 1 个视觉元素 |
| 图解 blueprint | 网格底、坐标、逐步高亮、线条绘制 | 网格线要极淡（`--mp-faint` + 低透明度） |
| 冲刺 drill | 卡片网格、公式块、速查表，反转强调关键项 | 密度高但≤ 5 块，别塞满 |
| 叙事 story | 横向时间线、场景块、逐步揭示 | 节点≤ 8，同屏只展开 1 个详情 |

Manifest 的 `layout` 只是元数据；实际版式可按知识点微调，但必须遵守第 5 节预算。

## 8. reduced-motion 与深浅色

- 宿主在 `<html>` 上设置 `data-mp-reduced-motion="true"`。页面必须在此属性存在时**关闭过渡与动画**：

```css
html[data-mp-reduced-motion="true"] .mp-page,
html[data-mp-reduced-motion="true"] .mp-page * {
  transition: none !important;
  animation: none !important;
}
@media (prefers-reduced-motion: reduce) {
  .mp-page, .mp-page * { transition: none; animation: none; }
}
```

- reduced-motion 下仍要能完成交互：状态必须**立即**切换（直接改属性/文字），不能依赖动画结束回调。
- 不要用 `setTimeout` 承担状态推进；状态立即更新，动画只是视觉过渡。
- 深浅色：所有颜色来自 `--mp-*`，因此无需额外规则；不要写死深色适配，也不要自己判断主题。
- 图示（SVG）用 `stroke: var(--mp-ink)` / `fill: var(--mp-raised)`；避免大面积纯 `--mp-ink` 填充，深色下会过重。

## 9. 「像动态 PPT 而不是网页作业」的正反例

- 正例：一屏一个论点；主视觉占 55%–65% 宽；3 个短注释；一个主按钮；动作只推进状态。
- 反例：顶部导航 + 面包屑 + 大段正文 + 滚动卡片；多个同等重要的按钮；彩色高亮；自动循环动画；页脚放参考资料链接。
- 反例：为了塞内容把正文降到 12px 并加两列滚动；或把所有推导一次铺满，再用动画装饰。
- 自检：眯眼看页面，能否一眼看出「先看哪、再看哪、点哪里」；若不能，删内容而不是加装饰。
