# 复习页方向评分标准（P14）

三个方向使用**同一份内容**、同一个渲染器，只切换布局与排版。评分只针对「这一版能不能让学生愿意读、读得懂、记得住」，不评价主题名称或实现技术。

评分范围 0–100，按下列六个维度加权。每个维度先给 0–100 的原始分，再乘权重求和。

| 维度 | 权重 | 看什么 |
|---|---:|---|
| 教学效果 | 25% | 每页是否有明确目标、核心结论、讲解/例题步骤、误区、检查；检查是否真的检验目标；内容是否来自资料而不是空话。 |
| 阅读体验 | 20% | 正文字号/行高/行长；层级与扫读路径；公式可读性；滚动是否自然；首屏是否能读到核心结论。 |
| 信息密度 | 20% | 首屏有效信息量；留白是否服务于阅读；是否仍有「为图而图」；flow 页 2–2.6 屏、fit 页单屏是否合理。 |
| 图示价值 | 15% | 图是否服务当前讲解；2–4 个状态是否真有教学意义；是否喧宾夺主；caption/takeaway 是否给出结论；无图页面是否仍成立。 |
| 视觉完成度 | 10% | 对齐、间距、边界、暗色、390 移动端、reduced-motion；有无标签碰撞、裁切、溢出；细节是否像成品。 |
| 生成可行性 | 10% | 同一内容换主题是否稳定；结构是否可由模型稳定产出；校验规则是否可落地；后续 14–16 页批量生成是否可控。 |

## 分档参考

| 分数 | 含义 |
|---:|---|
| 90–100 | 可以直接作为主基调；只需局部打磨 |
| 75–89 | 方向成立，有明显优点，也有需要修的具体问题 |
| 60–74 | 能用但不够好；需要较大调整才建议作为主基调 |
| < 60 | 不建议作为主基调 |

## 评分时必须回答的问题

1. **首屏**：学生第一眼看到的是「要学什么 + 为什么重要」，还是一个占面积的图？
2. **正文**：连续读三段是否舒服？字号、行长、行高是否像讲义而不是仪表盘？
3. **图**：如果删掉这张图，这一页的教学是否基本不受影响？如果不受影响，图就是点缀；如果受影响，图是否承担了明确的教学职责？
4. **检查**：选项、反馈、解析是否构成一次真正的回忆练习，而不是装饰？
5. **移动端**：390px 下是否还能读？是否有横向裁切、公式不可读、图被挤到无意义的位置？
6. **暗色**：对比度、边界、图内文字是否仍然清楚？
7. **批量生成**：如果让模型按这个结构连写 15 页，排版会不会崩？哪些地方依赖人工微调？

## 输出格式（盲评子代理）

只返回一个 JSON 对象，不要附加 Markdown 代码块以外的解释：

```json
{
  "judge": "J1",
  "directions": {
    "A": {
      "teaching": 0,
      "reading": 0,
      "density": 0,
      "figure": 0,
      "polish": 0,
      "feasibility": 0,
      "total": 0,
      "reasons": {
        "teaching": "一句话，引用具体页面/截图",
        "reading": "一句话",
        "density": "一句话",
        "figure": "一句话",
        "polish": "一句话",
        "feasibility": "一句话"
      },
      "best_page": "page-1 / page-2 / page-3",
      "main_issue": "最需要修的一个问题"
    },
    "B": { "...": "同上" },
    "C": { "...": "同上" }
  },
  "ranking": ["A", "B", "C"],
  "overall": "80 字以内总结三个方向的核心差异"
}
```

`total` 必须等于六个维度按权重加权后的整数（四舍五入）。不要因为「都差不多」而给三个方向相同分数；必须排序。
